# KMI profiles

`profiles/<kmi>.json` is generated by `tools/gen_profiles.py`. It records the
per-KMI native capability matrix and each feature's target level. It is not a
claim of validation: `validated` stays false until the QEMU/device evidence is
attached to a release.

Current stage: `android16-6.12` development wrap-up. The per-feature
implementation status (native, development, not shipped) is recorded in
`docs/status.md` only; it is deliberately not duplicated here, because a
generator cannot know it and a hand-maintained copy drifts. `ipset` EL0 and E5
unload are not verified. No entry is validated.
